## Autor

## Descrição

Aplicação web que consulta a PokéAPI e exibe a ficha de qualquer Pokémon a partir do nome ou do número. Útil para quem quer checar rapidamente tipo, tamanho e atributos de um Pokémon sem instalar nada.

## API utilizada

* PokéAPI — https://pokeapi.co/docs/v2
* Endpoint consumido: `GET https://pokeapi.co/api/v2/pokemon/{nome-ou-id}`

## Funcionalidades

* Buscar um Pokémon digitando o nome (ex.: `pikachu`) ou o número (ex.: `25`)
* Buscar pelo botão ou apertando Enter no campo
* Sortear um Pokémon aleatório entre os 1025 disponíveis
* Exibição da ilustração oficial do Pokémon
* Ficha com número, tipos, altura, peso, habilidade e barras de HP, Ataque e Defesa
* Mensagens de erro amigáveis para nome inexistente, API fora do ar, falta de conexão e campo vazio
